# Release notes

## 2.0.1

Зручніше ставити точки у редакторі форми (як у ShaperBox 3):
- **Один клік по порожньому місцю ставить точку** (раніше треба було двічі клікати або тягнути). Подвійний клік по точці її видаляє, але точку, щойно поставлену першим кліком, подвійний клік не прибирає.
- **Клік біля самої лінії ставить точку прямо на лінію**: форма не змінюється, а вигнутий відрізок ділиться на дві половини, що повторюють стару криву.
- **Видно, куди ляже точка**: під курсором кружечок «+» на місці з урахуванням прив'язки. Поки тягнеш точку, видно вертикальну й горизонтальну напрямні.
- **Горизонтальна сітка тепер збігається з прив'язкою** (16 рівнів). Раніше було намальовано 8 ліній, а точки липли до 16 рівнів, тому лягали між лініями.
- Новий відрізок після доданої точки починається прямим, а не копіює вигин сусіднього: більше немає несподіваних хвиль.
- Точки й кільця вигину легше вхопити (більша зона).
- Назва і довжина лінії більше не закривають кінцеву точку в правому верхньому куті.
- Linux: затиснута ліва кнопка миші більше не сприймається як Alt.

## 2.0.0

Повністю новий WaveCube: модульний ланцюжок, як у великих шейперах, і нічого не обмежено.

- Ланцюжок до 12 елементів, будь-які типи й порядок, **один тип скільки завгодно разів** (два Drive, три Volume…). Меню правою кнопкою: дублювати, замінити, додати після, копіювати / вставити, скинути, прибрати.
- Нові елементи: **Reverb** (14 просторів + свої IR), **Liquid** (flanger / phaser), інструменти **Compressor** (мультибенд, сайдчейн, графік GR і крива) і **Scope**.
- Дві форми (лейни) у Filter (Cutoff / Resonance), Noise (Volume / Pitch), Crush (Bits / Resample), Reverb (Send / Volume), Liquid (Centre / Feedback); зсув (offset) кожної форми перетягуванням, автоматизується.
- LFO і envelope follower окремо для кожного лейна і кожної смуги; смуги зв'язані або вільні; Beat / Hz / Pitch; тригер Sync / MIDI / Audio з налаштуваннями (алгоритм, чутливість, зсув, фільтри, сайдчейн); 1-shot з маркером кінця.
- Envelope: вхід смуга / повний із фільтрами / сайдчейн, Depth ×1…×8, Shift, Adaptive, Add / Multiply, Listen.
- Filter: Clean / Warm, Safe res, Hard dist, крива АЧХ. Drive: 12 стилів, крива. Noise: 24 шуми + свої WAV. Time: стрибки «cut» (чистий кросфейд) або «glide», до 16 с назад.
- Редактор: інструмент Select (виділення рамкою, рух, видалення), форми за категоріями для кожного типу, To all bands, Undo / Redo усього.
- **136 заводських пресетів** у 8 категоріях і 64 пресети елементів; фільтр браузера за елементами, випадковий пресет ⚄, збереження пресетів окремих елементів.
- Налаштування (⚙): аудіотригер, MIDI-канал, MIDI Switch, захисний кліпер, розмір вікна, папки пресетів / шумів / IR.

Звук і швидкодія:

- Без клацань при будь-яких змінах: структурні зміни (ланцюжок, тип, смуги, слоуп) йдуть через короткий перехід, лінії затримки заповнюються до того, як елемент чути.
- Однаково звучить на 22.05–192 кГц і на будь-якому розмірі блоку; без DC у Crush; без денормалів у тиші.
- Приблизно вдвічі швидше за першу збірку v2: швидкі log / exp, без копіювання стану на кожному семплі, детектор аудіотригера спить, коли не потрібен.
- 64 автотести, серед них аудит кліків, частот дискретизації, блоків, темпу й тиші.
